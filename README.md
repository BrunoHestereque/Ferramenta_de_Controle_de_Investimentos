# 📊 Controle de Investimentos Imobiliários

Esta planilha foi projetada para realização de simulações de investimentos em fundo imobiliários.

---

## 🚀 Funcionalidades

- **Visualização de Dados:** Dashboard intuitivo com gráficos para análise rápida da evolução do patrimônio.
- **Métricas Chave:** Monitoramento de retorno sobre o investimento e distribuição da carteira.
- **Simulações:** Simulações de investimentos com base no quanto deseja investir, por quanto tempo e com qual taxa. Com apresentação de cenários futuros para a simulação.

---

## 🛠️ Tecnologias e Recursos Utilizados

- **Microsoft Excel**
- Funções avançadas (PROCV, VF)
- Gráficos Dinâmicos de acompanhamento evolucional
- Validação de Dados

---

## 📂 Como Utilizar

1. Faça o download do arquivo `.xlsx` disponível neste repositório.
2. Abra o arquivo no Microsoft Excel (ou Google Planilhas).
3. Cadastre seus dados na aba Configurações e preencha os campos para simulação na aba Simulador.
